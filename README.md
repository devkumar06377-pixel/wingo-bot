# Wingo AI Predictor Bot

## Deploy on Railway (Free, 24/7)

1. Go to https://railway.app
2. Sign up with GitHub
3. Click "New Project" → "Deploy from GitHub repo"
4. Upload these files OR use GitHub
5. Add Environment Variable:
   - Key: BOT_TOKEN
   - Value: your telegram bot token
6. Deploy!

## Commands
- /predict — Get prediction
- /add <period> <number> — Add result (e.g. /add 10644 7)
- /result <number> — Verify last prediction
- /accuracy — See accuracy stats
- /history — Last 10 results
- /clear — Clear data
